# Open Tickets — Premium Live Events Frontend

A responsive, multi-page Open Tickets frontend with a restrained ivory, deep-navy and ticket-gold palette. The homepage keeps its image-only hero size and automatically rotates complete artwork, including an illustrative pre-match football lineup banner, official event banners and a newly generated panoramic concert-crowd image based on the supplied visual reference. The Next 7 Days deck contains only verified listed events beginning in that window—never padded placeholders—and uses a five-position desktop / three-position mobile fan whenever enough real events qualify; when fewer qualify, only those actual event cards appear. Its white, rounded, image-led event cards retain the center emphasis, arrows when multiple events qualify, swipe/drag, keyboard, and flip interactions; the number/dot pager is removed. Shared upcoming-event cards use site-provided event details and imagery, with no copied sample listing, reviews, or amenities from the visual reference. A new Appel concert feature sits immediately above the footer. Gold accents remain solid for clarity; gold gradients have been removed from text and shapes. The supplied white Open Tickets logo sits on a deep-navy header band with a restrained solid-gold lower rule; the footer retains its supplied mark. A compact CSS custom-property set keeps core brand colours, typography and surfaces easy to retheme, while the SVG icon system stays brand-consistent.

## Pages

- `index.html` — The full-width image-only hero sits directly below the header at its existing size, followed by the trust ticker and “Next 7 Days” carousel. The hero rotates an AI-generated panoramic concert crowd, illustrative pre-match football artwork and upcoming event imagery; the concert scene is atmospheric artwork, not an official event poster, and the football image is not a specific fixture photo. The deck targets five cards on desktop and three on mobile when that many actual listings qualify within seven days; if fewer real events qualify, it shows only those cards and never pads the deck with placeholders. The 29 October 2026 snapshot has three verified events inside the upcoming seven-day window—ISR Sewes en Hoops, KempieFees 2026 and Mamelodi Sundowns vs Durban City, all on 31 October—so it shows those three real cards rather than inventing two more; the deck supports five desktop positions whenever five or more actual listings qualify. White, rounded, image-led cards display site-provided details and images. The 3D deck emphasizes the centered card with up to four surrounding cards on desktop or two on mobile; arrows appear only when multiple real events qualify. Side-card selection, swipe/drag, keyboard and flip interactions remain, without a number/dot pager. Search/category controls and featured tickets follow below. A new Appel concert feature sits immediately above the footer. Featured tickets retain the layered desktop collage and mobile snap/swipe row. Shared cards use a lower-right day/month badge, venue/category, event title, date/time, available price information, “View ticket” and official “Buy ticket” actions.
- `events.html` — All-events page with its own generated hero, event search, working category filters, sort control and cards from the existing listing data.
- `sports.html` — A dedicated football/sports page with its own stadium AI hero, football-only results, count and sort controls. Its hero search carries the football filter into Search.
- `music.html` — A dedicated music page with its own concert AI hero and music-only event cards.
- `outdoor.html` — A dedicated outdoor page with its own scenic outdoor-event AI hero and outdoor-only event cards.
- Category pages are separate local routes; they use the same responsive card system and display only listings matching their category. Each page’s compact hero search is centered and a continuous, accessible ticker directly below the hero rotates through that page’s real event titles and dates; reduced-motion preferences are respected.
- `search.html` — AI-art search hero with keyword and location search, date/category/price/venue filters, sorting, pagination, result count and empty state. Search results share the same white rounded card style, site-provided details and official ticket-action links.
- `event.html?id=kaizer` — The selected event’s own poster image fills the full-bleed hero, with a readable dark overlay and matching event title/date/venue. The About this event section is editorially structured, the venue panel embeds a Google Map and directions link, and the premium Ticket Options panel retains event-specific tiers, quantity, estimate and official booking hand-off.
- `faq.html` — AI-art customer-care hero, five FAQ categories, live search and accessible accordions.
- Shared header — Events, Sports, Music and Outdoor each link to a distinct local page with a category-specific hero and listing. A navy color band carries the supplied white Open Tickets logo, light navigation text and a thin gold rule. It stays pinned at the top and shrinks on scroll. Desktop actions are “Sign up” and “Log in”; on mobile they appear in the expanded navigation menu. “Log in” opens the official email magic-link page. The official service has no separate manual sign-up flow, so “Sign up” opens its account-creation guidance; accounts are created during ticket purchase. Search remains in the desktop header and immediately left of the menu on mobile.
- Mobile navigation — Four-item floating deep-navy pill for Home, Events, Tickets and Profile, styled after the supplied reference with a raised active disc, a rotating multicolour halo and coordinated spectrum cycling on the active disc and icon. A gold active label remains visible; only the active item’s name is shown visually, while inactive names remain available to assistive technology. Home and Events open local pages. Tickets opens the official bookings route, which redirects signed-out visitors to the My Bookings login. Profile opens the official account/profile guidance; it is not presented as a separate user dashboard. Safe-area spacing is included for modern phones.
- Mobile section copy — Explanatory text under section, event-card and trust headings is tucked away until the heading is tapped; desktop descriptions remain visible.

## Run locally

From this folder, run:

```bash
python3 server.py
```

Then visit `http://localhost:4173` (or set `PORT=4174` for the alternate preview port). The preview server reads the public Open Tickets homepage for current hero banners and event dates, refreshes its short-lived cache every five minutes, and serves those images through a same-origin proxy. If the live site is unreachable, the bundled event data remains as a fallback.

## Front-end notes

- Built with HTML, custom CSS, locally bundled Bootstrap 5 CSS and vanilla JavaScript. No remote font, icon or JavaScript assets are required for the local preview.
- The site uses a restrained 3D visual system: layered panel shadows, tactile buttons and card tilt, with reduced-motion preferences respected.
- AI-generated, brand-matched artwork is stored locally, including unique `assets/hero-events-category.jpg`, `assets/hero-sports-category.jpg`, `assets/hero-music-category.jpg` and `assets/hero-outdoor-category.jpg` hero images for the four listing routes, plus `assets/hero-search-ai.jpg`, `assets/hero-support-ai.jpg`, `assets/football-matchday-hero.png` and `assets/hero-home-concert-ai.png`. The event-detail hero itself now loads the selected event’s own banner. The football artwork is illustrative and carries no team branding; event-specific details continue to show the matching event poster separately.
- The custom ticket-led SVG icon system is in `assets/icons.svg`; the coordinated SVG browser icon is `assets/favicon.svg`.
- The supplied Open Tickets brief did not include the current Isotope source code. The refreshed pages preserve the `.isotope-filters`, `data-filter`, `.event-grid` and `.event-item` hooks and make the filters work with vanilla JavaScript. Reconnect the production Isotope engine during theme integration if the existing layout depends on it.
- The hero feed reads only publicly listed homepage banners and event dates from Open Tickets; ticket availability is not inferred from this feed. The seven-day deck includes only bundled/listed events whose start time falls within the next seven days; cards are never generated as placeholders. Event imagery and details come from the site dataset, and ticket availability is not inferred. The project does not implement live booking, payment, queue management, authentication, account access or refund status. Search filters the available listing data; displayed totals are estimates where applicable.
- Event cards display the minimum published ticket price verified from the official Open Tickets listing for each bundled event. These are a checked snapshot, not a live price or inventory feed; prices can change, so the official event page remains authoritative.
- The home hero rotates the generic football lineup, official upcoming-event banners and a newly generated 1696 × 624 panoramic concert-crowd image, preserving the existing image-only treatment and banner ratio. The AI concert scene is atmospheric artwork rather than an official event poster. Other event banners and the Open Tickets logo are local copies of public assets from the current Open Tickets website. Confirm usage rights and client approval before production deployment.
- All interface copy, source code and project documentation are in English.
